spatialrecipes contains extra steps for the
[recipes](https://recipes.tidymodels.org/) package for preprocessing
spatial data. It is an extension package in the same vein as
[textrecipes](https://textrecipes.tidymodels.org/),
[embed](https://embed.tidymodels.org/), and
[themis](https://themis.tidymodels.org/).

> \[!NOTE\] This package is in early development and does not contain
> any steps yet.

## Installation

You can install the development version of spatialrecipes from
[GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("EmilHvitfeldt/spatialrecipes")
```
